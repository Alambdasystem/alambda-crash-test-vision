The video is a silent 1080 × 1350 H.264 MP4 lasting approximately 18.6 seconds. It uses the source recording's playback clock, followed by a 0.25× source replay and manually placed contact hold. The original recording already contains slow motion.

The code ZIP includes the processing and rendering scripts, source excerpt, actual detector observations, summaries, licenses, and preview. It does not contain model weights; the supplied downloader retrieves them when needed.
