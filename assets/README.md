# Source assets

[source.mp4](source.mp4) is the six-second excerpt included for immediate rendering. [source.json](source.json) records its exact hashes, extraction, playback rate, and manually reviewed contact annotation.

See [SOURCE_ATTRIBUTION.md](SOURCE_ATTRIBUTION.md) for the NHTSA footage credit and the [project's third-party notes](../THIRD_PARTY.md) for licensing context. [YOLOX_LICENSE.txt](YOLOX_LICENSE.txt) retains the OpenCV Zoo model-directory license.

From the project root, run `python download_assets.py` to verify the sample and download the checksum-verified model. The model weights and full original recording are not committed.
